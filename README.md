# Site d'iCode

Site de présentation d'iCode, l'éditeur de code et client Git natif pour iPhone, iPad et iPhone pliable.

En ligne : https://kmcapitalgroup.github.io/icode-site/

- `index.html` : page d'accueil en français, `en/` : version anglaise
- `confidentialite/`, `support/`, `en/privacy/`, `en/support/` : pages légales et aide
- `idatabase/` : page de présentation d’IDatabase, le client de bases de données de la famille iCode (identité « Nocturne », styles et scripts dans `idatabase/assets/`)
- `assets/` : styles, scripts (démo animée de l'éditeur, interactions) et images

HTML, CSS et JavaScript statiques, sans build. GitHub Pages sert la branche `main`, dossier racine.
