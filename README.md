# Site d'iCode

Site de présentation d'iCode, l'environnement de développement Swift et client Git natif pour iPhone et iPad.

En ligne : https://kmcapitalgroup.github.io/icode-site/

- `index.html` : page d'accueil en français, `en/` : version anglaise
- `confidentialite/`, `support/`, `en/privacy/`, `en/support/` : pages légales et aide
- `runner/`, `en/runner/` : téléchargement d'iCode Runner (Mac compagnon)
- `assets/` : styles, scripts (démo animée de l'éditeur Swift, interactions) et images
- `assets/captures/{fr,en}/` : vraies captures de l'app (WebP, tirées des captures App Store brutes du dépôt iCode)
- `assets/partage.jpg`, `assets/partage-en.jpg` : images de partage (Open Graph) FR et EN

HTML, CSS et JavaScript statiques, sans build. GitHub Pages sert la branche `main`, dossier racine.
