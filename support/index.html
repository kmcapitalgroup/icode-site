Support

Une question, un bug ou une idée ? On te répond.

Nous écrire

Écris-nous à kevinm@kmcapitalgroup.fr. Pour un bug, précise ta version de macOS, celle d’iCode (menu iCode › À propos) et les étapes pour le reproduire.

Installer iCode

Télécharge iCode depuis la page de téléchargement, ouvre le fichier iCode.dmg et glisse iCode dans le dossier Applications. iCode est gratuit, signé et notarisé par Apple : macOS l’ouvre sans avertissement.

Ajouter une clé d’IA

Réglages › Assistant IA › choisis ton fournisseur, puis colle ta clé. Le lien pour créer une clé chez chaque fournisseur est indiqué dans l’app. Sans clé, l’éditeur, le terminal et Git restent complets.

Se connecter à un dépôt privé

Avec GitHub, utilise « Se connecter avec GitHub » dans le panneau Git : aucun jeton à créer. Pour un autre hébergeur, ouvre « Dépôt distant et jeton… » et colle un jeton d’accès personnel ; il est rangé dans le Trousseau.
